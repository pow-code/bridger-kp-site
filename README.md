# bridger-kp-site

Продающий одностраничный сайт Bridger для локального бизнеса (тёплый артефакт после звонка). Адресат — владелец заведения Академгородка; цель — рассказать оффер и привести в Telegram.

## Стек
- Статика: HTML + CSS + vanilla JS. Без бэкенда, без формы, без сборки.
- [GSAP 3 + ScrollTrigger](https://gsap.com/) — reveal/инфографика/count-up/параллакс (CDN).
- [Lenis](https://lenis.darkroom.engineering/) — плавный скролл (CDN).
- Шрифт Inter (Google Fonts).

## Структура
```
index.html              # разметка + контент (9 секций)
assets/css/styles.css   # дизайн-система + секции + эффекты (Слой 3)
assets/js/main.js       # Lenis + GSAP + курсор + count-up (Слой 4)
assets/img/             # og.png (под дизайн frontend-design — пока нет)
```

## Запуск локально
Открыть `index.html` в браузере (двойной клик) — статика, сервер не нужен. Для корректной проверки моушна — онлайн (CDN-скрипты).

## Деплой
GitHub Pages: запушить в публичный репозиторий, включить Pages на ветку `main` (корень). `.nojekyll` отключает Jekyll. Альтернатива — перетащить папку на [app.netlify.com/drop](https://app.netlify.com/drop).

## Инварианты (важно при правках)
- **Честность:** ноль выдуманных цифр. count-up — только на реальных числах §6 (575 / 500+ / ~8%). Портрет §4, чипы §8, мокапы §2, мотив §7 — плейсхолдеры с меткой «концепт».
- **Дисциплина акцента:** near-black + единственный purple-акцент. Orb-бюджет = 2 (hero + финальная CTA).
- **`prefers-reduced-motion`** уважается; при отключённом JS/CDN контент полностью виден.
- **Один primary-CTA** (Telegram), attention 1:1, без меню/формы.
